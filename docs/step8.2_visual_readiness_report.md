Geometric QA over all 12 slides, checking every shape's bounding box:

**Three defects were found and fixed during this step:**

1. **Title and subtitle overlapped by 0.04 in on 11 slides.** Subtitle offset corrected.
2. **Slide 10's ML banner overlapped the source line by 0.13 in.** Row pitch tightened 0.94 → 0.89 in.
3. **Tight single-line text in four places** (slide 1 cards, slide 6 confidence column, slide 7
   captions). Column widths and font sizes adjusted. Remaining long lines wrap within their box
   height — PowerPoint wraps, and each box was checked to have room for the wrapped lines.

**Four defects were found and fixed in the diagrams:**

1. The first architecture render was **clipped at the bottom** — the serving layer was cut off.
   Canvas raised 1560 → 1760 px.
2. Two annotations overlapped neighbouring boxes (`LICENCE GATE`, `consulted…`). Both repositioned.
3. **Arial has no `◪`, `⬚`, `✓` or `✗` glyphs** — they rendered as tofu boxes. The tier markers and
   tick/cross are now **drawn as shapes**, which is also truer to the product's rule that status is
   carried by shape and not colour alone.
4. Two figures had large dead space below the content. Canvases trimmed.

## 8. Environment limitations encountered

| Limitation | Consequence | Mitigation |
|---|---|---|
`python-pptx` not installed; dependencies frozen | Could not use a PPTX library | Wrote the OOXML package directly with stdlib `zipfile`. **Deck generated.** |
No PowerPoint / LibreOffice / working QuickLook | PPTX could not be **rendered** for visual inspection | Validated package structure, XML well-formedness, relationship integrity and shape geometry. **A human must open it once.** |
No SVG rasteriser (`rsvg-convert`, ImageMagick, Inkscape all absent) | Could not convert SVG → PNG | PNGs are generated **directly** with Pillow; the SVG is an independent hand-written companion, not a conversion. |
Chrome inherits the system dark appearance in headless mode | First captures came out dark | `--blink-settings=preferredColorScheme=1` forces light. Documented in the re-capture guide. |
Arial lacks several box and tick glyphs | Tofu boxes in the first renders | Markers are **drawn as shapes** instead. |

**No project dependency was added and no implementation file was modified to work around any of
these.** Chrome and Pillow were already present; Pillow arrives as a transitive dependency and is
used here only by presentation scripts outside the pipeline.
